# Project Fluxus

> 音楽をプログラムするのではなく、育てよう。

---

## Project Fluxusとは

Project Fluxusは、リズムマシンでも、DAWでもありません。

時間とともに音楽が変化し、成長していく「生成する楽器」を目指すプロジェクトです。

ユーザーは音符を打ち込むのではなく、
音楽に少しだけ手を添えます。

あとは楽器自身が考え、
記憶し、
変化し、
ときどき思いがけない美しい景色を見せてくれます。

---

## コンセプト

Project Fluxusが目指すのは、

「曲を作ること」

ではありません。

「音と一緒に時間を過ごすこと」

です。

コーヒーを飲みながら。

本を読みながら。

静かに、ミニマルに。

夜、照明を少し落とした部屋で。

ずっと同じではない。

でも別の曲になるわけでもない。

生き物のように少しずつ変化していく。

そんな楽器を目指します。

---

## 開発思想

Project Fluxusでは、複雑さを表に出しません。

裏側では高度なアルゴリズムが動いていても、
ユーザーが触れるのは最小限です。

理想は、

「説明書を読まなくても触り始められる楽器」

です。
---

## 音の世界

Project Fluxusが目指すのは、派手な電子音ではありません。

静かなアンビエンスの中に、
小さなグリッチが呼吸する世界です。

音は少しずつ変化し、
ときどき美しいテンションコードが景色のように現れます。

グリッチと静寂。

秩序と偶然。

デジタルと有機。

その境界にある音楽を目指します。

## このプロジェクトで一番大切にしたいこと

Project Fluxusは、

「便利なソフト」

を作るプロジェクトではありません。

「時間を忘れて触ってしまう楽器」

を作るプロジェクトです。

音楽は完成品ではなく、
生き物のように呼吸し、
育ち、
変化するもの。

その体験を届けることが、このプロジェクトの目的です。
